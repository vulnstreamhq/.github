# Security policy

Do not report credentials, private exploit details, customer data, or sensitive package inventories in a public issue.

Use private vulnerability reporting on the affected repository when it is enabled. If no private reporting route is available, contact the organization owner through an existing private channel and identify only the affected project until a safe exchange is established.

Vulnstream is currently a private alpha without a public security-response SLA. A monitored security address, acknowledgement target, coordinated-disclosure timeline, safe-harbor policy, and encryption option are launch requirements.
